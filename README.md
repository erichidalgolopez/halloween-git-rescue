# Halloween Git Rescue — Forensic Software

## 1. Presentació i entorn

Aquesta pràctica consisteix a simular un incident de seguretat informàtica en un projecte de programari anomenat `server-room-horror`. L'objectiu és aprendre a utilitzar Git per controlar versions, crear branques, resoldre conflictes, restaurar estats anteriors i publicar un repositori a GitHub.

**Entorn de desenvolupament**

- Sistema operatiu: [Windows]
- Llenguatge de programació: Java
- Control de versions: Git
- Plataforma remota: GitHub

## 2. Taula de continguts

- [Bloc 1: Invocació del Repositori i Línia Base](bloc1.md)
- [Bloc 2: Les Branques del Més Enllà i Resolució del Conflicte](bloc2.md)
- [Bloc 3: Viatge Temporal, Exorcisme del Codi i Publicació Remota](bloc3.md)

## 3. Resultat final

Construccio d'una línia base de tres commits, creacció de dues branques independents i resolument manual d'un conflicte de fusió entre els modes `nightmare` i `sanctuary`.

Posteriorment, s'ha simulat una excepció espectral, s'ha inspeccionat la diferència i s'ha restaurat la branca principal al darrer commit segur.

## 4. Repositori remot

- URL de GitHub: [https://github.com/erichidalgolopez]
- Branca principal: `main`
- Branques de treball: `feature-nightmare` i `feature-sanctuary`

## 5. Conclusions

Aquesta pràctica demostra la utilitat del control de versions per mantenir la traçabilitat del codi, aïllar desenvolupaments paral·lels, gestionar conflictes entre branques i recuperar una versió estable d'un projecte.

Les captures de terminal incloses als blocs de documentació constitueixen les evidències de les operacions realitzades.
